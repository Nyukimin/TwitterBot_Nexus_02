## 📖 ドキュメントの使い方

### 新規開発者向け

1. **まず読むべきドキュメント**:
   - **統合版**: [`01_コーディング開発ガイド.md`](01_コーディング開発ガイド.md) - コーディングルールと実行方法
   - **統合版**: [`06_プロジェクト分析レポート.md`](06_プロジェクト分析レポート.md) - システム全体の概要を把握
   - **統合版**: [`04_基本仕様と作成ガイド.md`](04_基本仕様と作成ガイド.md) - 基本仕様を理解

2. **開発を始める前に**:
   - **統合版**: [`02_問題改善分析レポート.md`](02_問題改善分析レポート.md) - 現在の問題点と重要ルール
   - **統合版**: [`05_実装状況と拡張計画.md`](05_実装状況と拡張計画.md) - 現在の実装状況を確認

### 機能追加・拡張時

1. **設計段階**:
   - **統合版**: [`05_実装状況と拡張計画.md`](05_実装状況と拡張計画.md) - 拡張方針を確認
   - **統合版**: [`04_基本仕様と作成ガイド.md`](04_基本仕様と作成ガイド.md) - 仕様書作成方法を参照
   - Phase別仕様書（phase1-6） - 該当するPhaseの仕様を参照
   - [`07_モジュール設計仕様.md`](07_モジュール設計仕様.md) - モジュール設計を確認

2. **実装段階**:
   - [`08_完全実装仕様書.md`](08_完全実装仕様書.md) - 詳細な実装手順を参照
   - **統合版**: [`03_モジュール抽出ガイド.md`](03_モジュール抽出ガイド.md) - モジュール化が必要な場合

### 問題解決・改善時

1. **問題の把握**:
   - **統合版**: [`02_問題改善分析レポート.md`](02_問題改善分析レポート.md) - 既知の問題点と改善事例

2. **分析・検証**:
   - **統合版**: [`06_プロジェクト分析レポート.md`](06_プロジェクト分析レポート.md) - プロジェクト全体の分析と検証結果
