### **Phase 4-02: アーキテクチャ層TDD実装**

**ドキュメント**: [`12_Phase4_02_アーキテクチャ層TDD実装.md`](12_Phase4_02_アーキテクチャ層TDD実装.md)

**目的**: 4層アーキテクチャをTDDで段階的に実装

**実装時間**: 16-24時間

**対象層:**
1. **オーケストレーション層**（multi_main.py）
   - アカウント管理
   - 並列実行制御
   - コマンドライン引数処理

2. **ビジネスロジック層**（reply_processor.py）
   - AI応答生成
   - スレッド解析
   - 返信判定ロジック

3. **共有モジュール層**（shared_modules/）
   - 占星術計算（astrology/）

4. **インフラ層**（webdriver_stabilizer.py）
   - WebDriver安定化
   - エラーリトライ
   - ログ管理

**TDD実装順序:**
```
1. Layer 1（オーケストレーション層）テスト作成
2. Layer 1 最小実装（Green）
3. Layer 2（ビジネス層）テスト作成
4. Layer 2 最小実装（Green）
5. Layer 3（共有モジュール層）テスト作成
6. Layer 3 最小実装（Green）
7. Layer 4（インフラ層）テスト作成
8. Layer 4 最小実装（Green）

10. リファクタリング
```

## 🔄 TDD開発サイクル（全フェーズ共通）

```
┌─────────────────────────────────────────┐
│ 1. Red: テストを書く（失敗する）         │
│    - 仕様を理解                          │
│    - テストケース設計                    │
│    - テストコード実装                    │
│    - pytest実行（失敗確認）              │
│         ↓                                │
│ 2. Green: 最小限の実装で通す             │
│    - 最小限のコード実装                  │
│    - pytest実行（成功確認）              │
│    - エッジケース確認                    │
│         ↓                                │
│ 3. Refactor: コードをリファクタ          │
│    - コード整理・最適化                  │
│    - 重複コード削除                      │
│    - 命名改善                            │
│    - black/flake8実行                    │
│    - pytest実行（回帰テスト）            │
│         ↓                                │
│ 4. 次の機能へ（1に戻る）                 │
└─────────────────────────────────────────┘
```
